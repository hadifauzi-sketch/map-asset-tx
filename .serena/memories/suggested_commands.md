Windows commands for this project:
- `npm run dev` to start the Vite dev server
- `npm run build` to create a production build
- `npm run preview` to preview the built app
- `rg pattern` / `rg --files` for fast code search
- `Get-ChildItem` to list files
- `Get-Content path` to read files
The app uses Vite and React; there is no dedicated lint/test script in package.json.
